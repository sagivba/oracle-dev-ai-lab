שלב 01 - Goal 001 - התאמת זהות התבנית

פרויקט: DEVELOPMENT in Oracle using AI Lab

Repository: oracle-dev-ai-lab

תאריך: 2026-05-21

ענף עבודה: codex-cli/goal-001-template-alignment

סיכום

בוצעה התאמת זהות ממאגר תבניתי כללי אל פרויקט Oracle AI Lab. השינוי מבהיר שהמאגר הוא oracle-dev-ai-lab, ששם התצוגה הוא DEVELOPMENT in Oracle using AI Lab, ושקוד Flask/Python הקיים הוא תשתית starter שמורה בלבד ולא מימוש Oracle Lab.

קבצים שנוצרו

  • docs/stages/stage-01-task-goal-001-template-alignment.html

קבצים שעודכנו

  • README.md - נכתב מחדש כמסמך פרויקט Oracle AI Lab ולא כתיעוד תבנית כללי.
  • pyproject.toml - תיאור הפרויקט עודכן לזהות Oracle AI Lab.
  • src/oracle_ai_lab/__init__.py - הוסר שם package עם סיומת template.
  • src/oracle_ai_lab/config.py - ברירת המחדל של שם הפרויקט עודכנה, ונוסף docstring קצר.
  • docs/template-usage.md - הוסב למסמך legacy שמזהיר לא להריץ את סקריפט התבנית כחלק מעבודת Oracle AI Lab.
  • .github/CONTRIBUTING.md - עודכנה זהות המאגר ויחסו לתשתית starter שמורה.
  • TODO.md - Goal 001 סומן כ-DONE וההמלצה הבאה עודכנה ל-Goal 002.

החלטות שיושמו

  • שם התצוגה נשאר DEVELOPMENT in Oracle using AI Lab.
  • שם המאגר הטכני הוא oracle-dev-ai-lab.
  • שם חבילת Python נשמר כ-oracle_ai_lab.
  • לא נוספה תשתית Oracle Docker, SQL, התקנה, סקירה, אריזה או מימוש פונקציונלי.
  • unittest נשאר מנגנון הבדיקות.

הנחות חשובות

  • קוד Flask/Docker הקיים הוא starter infrastructure שמור, לא תוצר סופי של המעבדה.
  • docs/template-usage.md נשאר כדי להסביר מורשת תבניתית, אך אינו workflow פעיל לפרויקט.
  • לא עודכן scripts/init_from_template.sh, משום שהוא לא אמור לרוץ במסגרת עבודת Oracle AI Lab והמסמך מסמן זאת במפורש.

הערת כותרות קבצים

קבצי Markdown משתמשים בכותרת המסמך כ-purpose header. בקבצי Python שעודכנו קיימים docstrings קצרים. לא נוסף header ל-pyproject.toml משום שזה אינו מתאים נקית לפורמט הקובץ ולשינוי הזהות המצומצם.

בדיקות שלא הורצו ולמה

  • לא הורצו בדיקות Docker משום ש-Goal 001 אינו מממש Docker או Oracle DB.
  • לא הורצו בדיקות DB משום שאין עדיין Oracle lab container, install workflow או schemas.
  • לא הורצו DDL או DML.

מגבלות ידועות

  • המאגר עדיין כולל Flask starter app ותשתית Docker כללית; הם מסומנים כ-starter infrastructure בלבד.
  • מסמכי Stage 0 המרכזיים עדיין חסרים ויטופלו ב-Goal 002.
  • אין טענה לתאימות Oracle Docker, install, review, packaging או DB.
