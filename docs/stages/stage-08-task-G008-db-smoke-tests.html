ענף עבודה: codex-cli/g008-db-smoke-tests

סיכום

Goal 008 הוסיף את אובייקט ה-smoke המינימלי LAB_SMOKE_TEST ואת שכבת בדיקות ה-SQL smoke הראשונית של המעבדה. האובייקט הוא infrastructure-only בלבד, ומשמש לווידוא התקנה בסיסית של סביבת DB מקומית עתידית. הוא אינו מייצג יכולת עסקית ואינו חלק ממימוש release-management.

הבדיקות נוספו כקובצי SQL מנוהלים תחת db/tests/sql/, ונוסף script רשמי להרצתן בשם scripts/run-db-tests.sh. מצב quick של scripts/test.sh נשאר static/unittest ואינו דורש Docker או Oracle.

תיקון PR נוסף הפך את נתיב ההתקנה הפנימי לעקבי עבור clean local lab DB: db/install/00_create_lab_users.sql יוצר או מעדכן את משתמשי המעבדה המקומיים, כך ש-AI_APP_OWNER יכול להיות הבעלים של LAB_SMOKE_TEST.

  • db/install/install.sql - נוסף include מנוהל לאובייקט ה-smoke.
  • db/install/01_create_schema.sql - עודכנה ההבחנה בין שלד schema לבין אובייקט Goal 008.
  • scripts/install-db.sh - עודכן להעתקת עץ db/ המנוהל כדי שה-install יוכל לכלול קובצי source.
  • scripts/test.sh - נוסף gate אופציונלי ל-DB tests במצב full בלבד.
  • tests/test_repo_contract.py - נוספו בדיקות contract עבור ארטיפקטים של Goal 008.
  • docs/testing-strategy.md - תועדה שכבת SQL smoke tests כעתיד שהפך לשכבה קיימת.
  • docs/install-workflow.md - תועדה אינטגרציית LAB_SMOKE_TEST ל-install המנוהל.
  • TODO.md - Goal 008 סומן כ-DONE עם ראיות וללא סימון Goal 009.

החלטות שנשמרו

  • Git נשאר מקור האמת לכל שינוי DB.
  • כל שינוי DB מיוצג בקובץ SQL גרסתי תחת db/.
  • התקנה מתבצעת דרך db/install/install.sql בלבד.
  • משתמשי המעבדה נוצרים או מעודכנים רק דרך db/install/00_create_lab_users.sql.
  • בדיקות SQL רצות רק דרך קבצים מנוהלים תחת db/tests/sql/.
  • Python tests נשארים מבוססי unittest; לא נוסף pytest.

מגבלות בטיחות שנשמרו

  • לא בוצע חיבור לבסיס נתונים ארגוני.
  • לא בוצע חיבור לשום בסיס נתונים במסגרת המשימה הסטטית.
  • לא הופעל Docker.
  • לא הופעל Oracle DB.
  • לא בוצעו DDL או DML באופן אד-הוק.
  • לא נשמרו secrets, סיסמאות, tokens או connection strings אמיתיים.
  • לא נטענה תאימות runtime של Docker או Oracle.

מה לא נוסף בכוונה

  • לא נוספו טבלאות עסקיות כגון RELEASE_REQUESTS או RELEASE_ITEMS.
  • לא נוסף מימוש release-management פונקציונלי.
  • לא נוסף review workflow.
  • לא נוסף packaging workflow.
  • לא נוסף spec pipeline.
  • לא נוספו בדיקות utPLSQL עסקיות.

הנחות

  • הרצת SQL smoke tests דורשת סביבת Oracle Lab מקומית קיימת, container בשם oracle-dev-ai-lab-db, וערכי סביבה מקומיים שאינם נשמרים ב-Git.
  • ברירת המחדל של PDB נשארת FREEPDB1.
  • סיסמאות מקומיות יסופקו רק דרך .env לא מנוטר או דרך סביבת shell מקומית.
  • משתמשי המעבדה משתמשים ב-tablespaces המקומיים USERS ו-TEMP, בהתאם לברירת מחדל סבירה של Oracle Free lab.

מה לא הורץ ולמה

  • scripts/install-db.sh לא הורץ, כי חסרים משתני הסביבה המקומיים הנדרשים וה-container oracle-dev-ai-lab-db אינו רץ.
  • scripts/run-db-tests.sh לא הורץ מול Oracle מאותה סיבה.
  • לא הורצו Docker או Oracle runtime checks, ולכן לא נטענת תאימות runtime.

מגבלות ידועות

  • בדיקות SQL smoke הן שכבת runtime עתידית ותלויות בסביבת Oracle Lab מקומית.
  • DDL יצירת המשתמשים עודכן לנתיב מנוהל, אך לא הוכח runtime מול Oracle במסגרת תיקון זה.
  • אין עדיין workflow review או packaging.
