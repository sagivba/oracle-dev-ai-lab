הנחות חשובות

  • Goal 013 הוא צעד תיעוד וממשל בלבד.
  • ה-branch נוצר מה-baseline המבוקש של GitHub/main.
  • ה-QA worktree אינו חלק משלב היישום ולא נוגעים בו.

מחוץ לתכולה

  • לא נוספו טבלאות release-management.
  • לא נוספו constraints, indexes או seed data.
  • לא נוספו SQL tests להתנהגות עסקית אמיתית.
  • לא נוספו PL/SQL packages, package bodies, procedures או functions.
  • לא נוספו views או triggers.
  • לא שונו install, rollback, review, package, Docker או Oracle runtime behavior.
  • לא נוספו REST, ORDS, APEX או UI.
  • לא הייתה גישה לבסיסי נתונים ארגוניים ולא הורץ DDL/DML אד-הוק.
