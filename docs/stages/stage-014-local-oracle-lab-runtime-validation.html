מה לא אומת

  • לא אומת install idempotent חוזר על lab שכבר הותקן.
  • לא אומת QA worktree.
  • לא אומתו portability או onboarding למפתחים אחרים.
  • לא אומתה תאימות Oracle 19c.
  • לא אומתה פונקציונליות release-management עסקית.

הנחות

  • הולידציה שתועדה בוצעה ידנית ב-Dev בלבד.
  • קובץ .env והסיסמה נשארים מקומיים ואינם חלק מה-repository.
  • ה-install המוצלח מייצג clean install לאחר reset, לא התקנה חוזרת על DB קיים.

מחוץ לתכולה

  • לא נוספו טבלאות עסקיות, constraints, indexes או seed data.
  • לא נוספו PL/SQL packages, views או triggers.
  • לא נוספו REST, ORDS, APEX או UI.
  • לא שונו runtime scripts.
  • לא הייתה גישה לבסיסי נתונים ארגוניים.
  • לא נוספו secrets ולא בוצע commit ל-.env.
  • לא הורץ DDL או DML אד-הוק במסגרת Goal 014.
