מה נמצא ומה תוקן

התיעוד הפעיל הציג תמונות מצב מתקופות שונות. קובץ הפתיחה ומסמכי הממשל הציגו חלק מהתשתית כחסרה, אף שקובצי המימוש כבר נמצאים במאגר. משימת המסירה הופיעה עדיין כמשימת המשך, אף שכבר מוזגה.

  • התשתית הקיימת כוללת שירות Oracle מקומי, סקריפטים לניהול המעבדה, התקנה מנוהלת, בדיקות SQL בסיסיות, סקירה סטטית, שלד אריזה וכלי אפיון.
  • משימת T015 הושלמה ומוזגה בתאריך 22.05.2026 באמצעות PR #24. תאריך המיזוג אומת דרך GitHub.
  • PR #22 מתעד בדיקה מקומית קודמת של Oracle בתאריך 22.05.2026. הוא מוזג באותו יום. התיעוד מתייחס להתקנה נקייה לאחר איפוס בסביבת Dev ולבדיקות smoke, סקירה ואריזה.
  • ממצאי העבר אינם תוצאת הרצה חדשה. התקנה חוזרת על מעבדה מותקנת, ניידות למפתח אחר ובדיקות גיבוי ושחזור אינם מוכחים מרשומת Goal 014.
  • העבודה הפונקציונלית טרם התחילה. שלד חבילת ההפצה אינו מבצע deployment ואינו מעניק אישור לפריסה.

החלטות והנחות

נשמרו כללי המאגר. לא שונו קובצי SQL, Docker, CI, סקריפטים או כללי עבודה. דוחות השלבים ההיסטוריים נשארו ללא שינוי. תוצאות הבדיקה המקומית הקודמת מיוחסות למקורות המתעדים אותן; הן לא שוחזרו במשימה זו. הסטטוס של Flask ושל CI נלקח מהתיעוד שמוזג במשימת המסירה ומהמימוש הקיים.

בדיקות שלא בוצעו והסיבות

  • לא הופעל Docker ולא בוצעו התקנה, בדיקות SQL, איפוס, גיבוי או שחזור. המשימה תיעודית, וכללי הבטיחות אוסרים חיבור למסד נתונים במשימת תיעוד. גם הפקודה docker אינה זמינה בסביבה.
  • לא הורץ scripts/package-release.sh ולא חודשו תוצרים במאגר, משום שמימוש האריזה לא השתנה. בדיקות החוזים שלו נכללו בבדיקות שעברו.
  • לא הורץ agw_review_output --run. הכלי אינו זמין בנתיב ההפעלה, ומודול המשנה שלו לא אותחל בעותק העבודה. בדיקות המאגר והסקירה הסטטית הורצו ישירות.
  • לא בוצעה בדיקת תאימות Oracle חדשה. הרצה נוכחית של Oracle, יכולות עסקיות ופריסה בפועל נשארו מחוץ לתכולה.
