# Historical Stage Reports

## Purpose

This directory contains completed Hebrew HTML stage reports for work already performed in `oracle-dev-ai-lab`.

These files are historical records. They are not active implementation instructions and should not be used as the source of truth for the next task.

## How to use this directory

Use these files when you need to understand:

- what was done in a previous stage
- which files were created or changed in a previous stage
- which assumptions, limitations, and validation results were recorded
- why a historical decision or implementation step happened

Do not use these files to decide what to implement next.

For the current project state and next action, use:

- `../../TODO.md`
- `../README.md`
- `../../AGENTS.md`
- active workflow documents under `docs/`
- current branch/task instructions

## Editing rule

Do not modify historical stage reports unless explicitly correcting a documented historical error.

New work that requires a stage report should add a new HTML file to this directory instead of editing old reports.
