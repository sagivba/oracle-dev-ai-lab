שלב 06 - Goal 006 - שלד Docker Lab בהתאמה למדריך Oracle 26ai

פרויקט: DEVELOPMENT in Oracle using AI Lab

Repository: oracle-dev-ai-lab

תאריך: 2026-05-21

ענף עבודה: codex-cli/goal-006-docker-lab-skeleton-blog-alignment

סיכום

נוצר שלד Docker מקומי עבור Oracle AI Database 26ai Free בהתאם למדריך של Sagiv Barhoom, תוך התאמה לשמות המחייבים של הפרויקט וללא שמירת סיסמאות אמיתיות. Docker לא הופעל במסגרת המשימה; בוצעה ולידציה סטטית בלבד.

מקור טכני שנקרא

  • https://www.sagiv-barhoom.me/oracle/2026/04/05/oracle_26ai_docker_setup.html

קבצים שנוצרו

  • scripts/lab-down.sh

  • scripts/lab-backup.sh
  • scripts/lab-restore.sh
  • docs/docker-lab-design.md
  • docs/stages/stage-06-task-goal-006-docker-lab-skeleton-blog-alignment.html

קבצים שעודכנו

  • docker-compose.yml - נוסף service בשם db עם Oracle image, volume, port ו-network.
  • .env.example - נוספו placeholders בלבד עבור Oracle image, password, port, PDB ו-backup root.
  • .gitignore - נוספה התעלמות מ-backups/.
  • TODO.md - Goal 006 ופריטי Stage 2 סומנו בהתאם לשלד שנוצר.

החלטות ודרישות שיושמו

  • Image: container-registry.oracle.com/database/free:latest
  • Container: oracle-dev-ai-lab-db
  • Volume: oracle-dev-ai-lab-u01
  • Network: oracle-dev-ai-lab-net
  • Mount: /opt/oracle/oradata
  • Port mapping: 1521:1521
  • PDB/service: FREEPDB1
  • Readiness marker: DATABASE IS READY TO USE!
  • Backup/restore משתמשים בקונספט של metadata + tar דרך container זמני של Alpine.

הנחות חשובות

  • המשתמש ייצור .env מקומי מתוך .env.example ויחליף את ORACLE_PWD בערך מקומי שאינו נשמר ב-Git.
  • המשתמש יתחבר ל-Oracle Container Registry ויאשר תנאים לפני pull/start בפועל.
  • השלד אינו מוכיח runtime עד ש-Docker יופעל והודעת readiness תופיע בלוגים.

בדיקות שהורצו ותוצאות

  • בדיקות syntax של Bash עברו.
  • בדיקת Docker Compose config סטטית עברה עם placeholder סביבתי זמני שלא נשמר בקובץ.
  • בדיקת grep לא מצאה שמות או סיסמאות לדוגמה מהמדריך שאסור להעתיק לפרויקט.
  • בדיקת מבנה אישרה שלא נוצרו תיקיות db/, specs/ או tools/.
  • scripts/test.sh quick נכשל בהרצה רגילה כי python לא נמצא ב-PATH.
  • PATH=.venv/bin:$PATH scripts/test.sh quick עבר בהצלחה.
  • scripts/lint.sh נכשל בהרצה רגילה כי python לא נמצא ב-PATH.
  • PATH=.venv/bin:$PATH scripts/lint.sh עבר בהצלחה.
  • פקודת unittest ישירה עם .venv/bin ב-PATH עברה בהצלחה.

בדיקות שלא הורצו ולמה

  • Docker לא הופעל ולא הורץ pull/up, בהתאם להנחיה לא להתחיל Docker ללא צורך מפורש.
  • לא בוצעו בדיקות Oracle DB משום שה-container לא הופעל.
  • לא הורצו install, review או packaging checks משום שה-workflows האלה עדיין לא קיימים.
  • לא הורצו DDL או DML.

מגבלות ידועות

  • אין טענה שה-Oracle container עלה בפועל.
  • אין טענה שהודעת DATABASE IS READY TO USE! נצפתה בפועל.
  • אין עדיין schemas, install workflow, smoke tests, review workflow או package workflow.

היעד הבא המומלץ

לפי סדר היעדים הרשמי, היעד הבא המומלץ עדיין הוא Goal 004 - Create Oracle Lab Repository Structure, משום ש-Goal 006 קודם לצורך התאמת Docker למדריך, אך Goal 004 ו-Goal 005 עדיין חסרים.
